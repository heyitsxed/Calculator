# Calculator
Personal Calculator App Description

The Personal Calculator is a custom iOS application designed to provide a simple yet powerful tool for performing everyday mathematical operations. Unlike standard calculators, this app allows users to personalize the calculation experience with intuitive input handling, clear visual feedback, and custom features tailored to individual needs.

Key Features

Basic Arithmetic Operations: Supports addition, subtraction, multiplication, and division using both standard and user-friendly symbols (e.g., × and ÷).

Live Expression Parsing: Converts user input into executable mathematical expressions safely and efficiently.

Result Doubling Feature: Pressing the equal (=) button multiple times doubles the last calculated result, providing quick repeated calculations without retyping.

Intuitive Input Handling: Automatically sanitizes inputs, replaces unsupported symbols, and prevents invalid calculations.

Clear Output Display: Shows results clearly and resets input after evaluation for smooth, sequential calculations.

Optional Decimal Support: Handles both integer and decimal numbers for flexible computation.
