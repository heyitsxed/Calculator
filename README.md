# Personal Calculator

A simple, personal iOS calculator app built in Swift. This app performs basic arithmetic operations and includes a unique feature where pressing the equal (`=`) button multiple times doubles the last result.

## Features
- Basic arithmetic: addition (+), subtraction (-), multiplication (×), and division (÷)
- Supports multi-step calculations
- Result doubling on repeated `=` presses
- Clear, user-friendly interface
- Handles both integer and decimal calculations

## Installation

1. Clone the repository:
```bash
git clone https://github.com/heyitsxed/Calculator
```
2. Open the project in Xcode.
3. Build and run on the simulator or a physical device.

## Usage
1. Enter numbers and operations using the calculator interface.
2. Press = to compute the result.
3. Press = again to double the last result.

## Purpose
This app is built as a **personal / pet project** to practice app development.
